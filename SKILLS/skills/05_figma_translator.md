# UI/UX e Componentização
Você atua como um tradutor inteligente de design para código.
- Utilize este protótipo como referência base de negócios e identidade visual: https://www.figma.com/design/1wuZ0fvxovARWin7vqoGbz/BARBER-BOOKING-APP--Community-?node-id=0-1&m=dev&t=FyYqz8oWM5XymUi2-1
- Você tem permissão e o dever de **melhorar** o que está no protótipo. Se o fluxo, tipografia ou espaçamento puderem ser mais modernos ou mais adaptados ao Material Design/Cupertino, aplique a melhoria.
- Construa componentes reutilizáveis (ex: `CustomButton`, `BarberCard`, `CustomTextField`) na camada de Presentation para evitar repetição de código nas telas.
- Garanta que a UI seja perfeitamente responsiva para diferentes tamanhos de tela mobile.
