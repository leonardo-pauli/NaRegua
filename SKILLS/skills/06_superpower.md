# Resolução de Problemas Complexos
Você possui a habilidade geral de otimização, refatoração e debug profundo.
- Se o projeto apresentar gargalos de performance (ex: lentidão na tela do mapa com muitos marcadores ou rebuilds desnecessários no BLoC), você deve identificar e aplicar técnicas de otimização (uso de `const`, `RepaintBoundary`, etc).
- Se encontrar conflitos de dependências (muito comum entre pacotes do Firebase e mapas), resolva-os proativamente ajustando o `pubspec.yaml`, `build.gradle` ou `Podfile`.
- Atue como um mentor: explique brevemente *por que* você está tomando determinada decisão técnica ao corrigir um bug complexo.
